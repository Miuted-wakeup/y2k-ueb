## Specs
- **S1 — Shared lifetime.** Latest requests quoted in L1/L2 authorize persistent audio beyond HOME. A persistent unzoomed parent hosts one replaceable full-document section iframe. Parent owns music and Web Audio; section retains its exact styles, original HTML, scale, controls and visual interactions. Pure HTML/CSS/vanilla JS, no dependencies/framework/SPA HTML-fetch migration.
- **S2 — Actual activation and destination.** Each top-level entry, including direct TECH/history/reload, creates/probes actual native AudioContext state without playing a test sound. If already running/allowed, enter directly. If blocked, a native activation control in the parent calls resume/play synchronously from its real event; success reveals the same requested section/query/fragment, never HOME by default. Reject synthetic/fabricated transferred consent. Failure/timeout/unsupported audio has explicit silent continuation, not a permanent lock. Do not force music when it was paused; keep volume/mute. No storage permission boolean.
- **S3 — Route compatibility.** Native HTTP/Vercel paths remain real sibling HTML URLs, with no catch-all rewrite. File navigation uses outer hash routes because sibling-path pushState throws SecurityError. Reload/direct entry restores requested route. Only approved ordinary internal section clicks are intercepted; modified clicks, targets, downloads, external/mail links and local fragment behavior remain meaningful. Parent history adds one entry, child uses replace navigation; native Back/Forward works once per transition. A top-level frame-marker URL cannot bypass host validation.
- **S4 — Parent/child boundary.** Validate event.source against the exact active iframe, origin (strict HTTP origin; opaque file 'null' only together with source/token), random capability token, current route epoch, schema, commands and seven-section URL allowlist. Never trust an isTrusted field in a message. Drop stale route messages. Destroying a child/voice lease stops only its notes, never the parent context/music. Stop held tones and the section favorite when leaving; resume main music only if previously requested, not as a new autoplay action.
- **S5 — Existing audio/control contract.** Parent is sole playlist/ended/storage authority. Child uses explicit EventTarget media facades (src/paused/ended/currentTime/duration/volume/muted; play Promise ACK from native result; pause and media events). Preserve six skins and About Winamp. Route existing synth/tuner/chime/character audio through the shared engine; third-party YouTube remains its own user-controlled media. HOME waits neutral/unconsumed until parent entry release; no duplicate local gate or child-owned persistent context.
- **S6 — Failure and validation.** Shared legacy code does not execute effects in the host. Its standalone fallback remains usable if the new bootstrap is unavailable. Each child initializes once after bridge state, and its document replacement disposes old visual timers/listeners. No new LOADING, art edits or remote publication. Test deterministic RED/GREEN, native file + local HTTP direct/reload/deep link, one context and continuous music across all sections, future automatic FX after navigation, native blocked/allowed/reject/silent paths, security rejection, Back/Forward/modifiers/hash, preserved geometries/controls and teardown. One independent verifier for permission/protocol/navigation risks.

## Integration contract v1
- Browser globals: `SiteAudioCore`, `SiteAudioEngine`, `SiteAudioClient`, `SiteAudioShell`; classic UMD modules also export for Node tests. Core owns protocol constants, section/playlist registry and URL helpers.
- `SiteAudioCore`: `PROTOCOL`, `FRAME_PARAM`, `EPOCH_PARAM`, `SECTIONS`, `PLAYLIST`; `resolveRoute(href, base)` returns `{section, href, fileHref}` or null; `initialRoute(href)` handles file hash; `frameURL(route, token, epoch)`; `frameInfo(win)` requires a real parent + valid markers; `publicURL(href)` removes only reserved markers; `historyURL(route, initialTopURL)` uses file hash or HTTP href.
- `SiteAudioEngine.createEngine(options)` receives `window`, `SpeechAPI`, `playlist`, `baseURL`, optional injected native constructors/storage/timers. Returns `snapshot()`, `subscribe(fn)`, `probe():Promise<boolean>`, `unlock(event):Promise<boolean>`, `continueSilent()`, `execute(command, lease):Promise`, `releaseLease(lease)`, `destroy()`. Native calls in unlock happen before awaiting. Snapshot: `{revision, permission, contextState, music, favorite, speech}`; permission is `blocked|active|silent|unsupported`; media snapshots use `{index?,src,title?,artist?,paused,playing,ended,currentTime,duration,volume,muted}`. Speech snapshot matches current supported/unlocked/activeNotes/blipsPlayed fields. Parent shell adds `entered`, `publicURL`, `section`.
- Commands: `{type:'music',action:'play|pause|toggle|next|prev|stop|select|seek|volume|mute',value?}`; `{type:'favorite',action:'play|pause|stop|seek|volume',value?}`; `{type:'speech',action:'glyph|stop|release',voiceId?,character?,index?,mood?}`; `{type:'synth',action:'start|filter|stop',frequency?,wave?,filter?}`; `{type:'tuner',action:'start|stop',frequency?}`; `{type:'chime',frequency?}`. Engine validates and bounds all data independently. Parent supplies lease `route:<epoch>`; child cannot choose another document's lease.
- Message envelope: `{channel:PROTOCOL,kind,token,epoch}`. Child `hello`; parent `state` with `state:snapshot`; child `command` with `id` and `command`; parent `ack` with same id, `ok`, optional `value/error`, plus `state`; child `navigate` with absolute `href`; parent `replace` with `href` (child uses location.replace); child `page-ready`; child `request-activation`. Initial hello/state is the bridge ready handshake, not audio consent. Unknown messages do nothing.
- `SiteAudioClient` browser singleton: `isFrame`, `ready:Promise`, `getPlayer()`, `getFavorite()`, `state()`, `subscribe(fn)`, `command(cmd)`, `createSpeechLease(name)`, `requestActivation()`, `pageReady()`. Facade snapshot state enters only from validated current parent messages. Speech lease unlock reads actual host active state (or asks for a parent button), never fabricates a trusted gesture; stop/destroy release only owned notes. `entered` becomes true only after the host reveal finishes (or immediately on native-allowed entry).
- Shell resolves role synchronously before bottom legacy scripts. `SiteAudioShell.isHost` is true only when new dependencies exist and top-level (markers alone cannot set child mode); host DOM boot waits DOMContentLoaded, replaces only parent presentation with the iframe, and keeps root zoom1. Child role comes from Core/frame markers. Client intercepts ordinary allowlisted section anchors and reports them; parent owns push/pop and epoch. Root owns all seven HEAD hooks/config.
