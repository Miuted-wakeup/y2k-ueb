# Ambient track stills

Small cover images for the shared ambient-track notice. Each PNG is one original
frame at 1 second from the already downloaded local source video. Existing local
FFmpeg extracted the frames without cropping, scaling or altering the source
videos, and with overwrite disabled. No new downloads were needed.

These are source-video illustrations, not independently verified official album
art or newly granted publication licenses. Original borders, text and watermarks
remain intact; presentation sizing belongs to the card's CSS.
