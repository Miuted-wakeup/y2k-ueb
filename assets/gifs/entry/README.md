## Portal intro experiment

`portal-intro.gif` is an unchanged copy of the user-supplied
`8572fed62a3c1afc00ac3d2b4833afe4.gif`: 600x450, 4,367,874 bytes, 90 frames,
infinite NETSCAPE loop, one declared cycle of 3010ms (59x30ms + 31x40ms).
Outer edges are opaque and textured; the shared entrance uses approximate mean
edge color `#150e14`, not an exact texture match. The source is not edited or
re-encoded. A fresh native image is removed after one timed cycle. Browser
playback/scheduling has not been verified; there is no native GIF ended event.
The previous collage assets remain preserved but are not used by this experiment.
